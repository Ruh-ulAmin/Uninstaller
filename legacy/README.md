# Legacy scripts

These PowerShell/batch scripts were the original prototype for this
project - interactive, console-only, and limited to a hardcoded or
manually-typed software list. They have been superseded by the real WPF
application in [`src/`](../src), which discovers installed programs
automatically, has a proper Windows UI, and adds batch uninstall, force
removal, and leftover cleanup that these scripts never implemented.

They're kept here for reference only and are not part of the build.
